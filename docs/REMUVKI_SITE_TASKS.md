# План задач: сайт ремувок «ЦЕХ»

Дата подготовки: 2026-08-16

## Этап 1. Подготовка перед разработкой

- Уточнить название и домен сайта.
- Выбрать основной оффер для первого экрана.
- Собрать 20-30 фото реальных ремувок или временные референсы.
- Уточнить список технологий MVP: сублимация, DTF, шелкография, вышивка, жаккард, ПВХ.
- Уточнить минимальные тиражи по каждой технологии.
- Подготовить базовые цены, коэффициенты срочности и упаковки.
- Решить, показываем ли точную цену или диапазон.

## Этап 2. Структура MVP

- Главная страница.
- Каталог технологий.
- Страница «Ремувки на заказ».
- Страницы «Ремувки Москва» и «Ремувки Санкт-Петербург».
- Калькулятор заявки.
- Загрузка макета.
- Портфолио/кейсы.
- Требования к макетам.
- Контакты.
- Политика конфиденциальности.

## Этап 3. Калькулятор

- Описать поля калькулятора.
- Задать правила валидации.
- Задать несовместимые комбинации.
- Подготовить формулу предварительного расчета.
- Сделать версионирование расчета.
- Подготовить структуру данных заявки.

## Этап 4. Интеграция с «ЦЕХ»

- Спроектировать таблицу/модель заявок с сайта.
- Сопоставить заявку сайта с заказом «ЦЕХ».
- Сопоставить позиции заявки с товарами заказа.
- Передавать файлы макетов.
- Создавать производственные задачи.
- Передавать плановую сумму и себестоимость.
- Настроить статус «Новая заявка» / «Согласование».

## Этап 5. Дизайн

- Сделать прототип главной страницы.
- Сделать прототип калькулятора.
- Сделать мобильную версию калькулятора.
- Подобрать визуальный стиль: современный производственный B2B, без перегруза.
- Подготовить карточки технологий.
- Подготовить карточки кейсов.

## Этап 6. Разработка

- Создать отдельный раздел или приложение для сайта ремувок.
- Реализовать главную страницу.
- Реализовать каталог технологий.
- Реализовать калькулятор.
- Реализовать отправку заявки.
- Реализовать загрузку файлов.
- Реализовать админский список заявок.
- Реализовать кнопку «Создать заказ в ЦЕХ».

## Этап 7. Проверка

- Проверить desktop и mobile.
- Проверить полный путь заявки.
- Проверить загрузку файлов.
- Проверить ошибки форм.
- Проверить передачу данных в «ЦЕХ».
- Проверить SEO-заголовки.
- Проверить скорость загрузки изображений.
- Провести QA-проверку.
- Провести проверку бизнес-логики калькулятора.
